# Flutter Easy Button Example

This example demonstrates all the features of the `flutter_easy_button` package.

## Features Demonstrated

### 🎨 Filled Buttons
- Basic filled button
- Filled button with icon
- Loading state button
- Full-width button
- Disabled button

### 🔲 Outlined Buttons
- Basic outlined button
- Custom border color and width
- Outlined button with icon
- Full-width outlined button

### 🎯 Real-World Examples
- Login form with primary and secondary actions
- Action buttons (Save/Delete) in a row
- Loading state simulation

## Running the Example

```bash
cd example
flutter pub get
flutter run
```
